## 2. Semantic review

**Question:** *If someone saw this identity with no explanation, would they understand Zirven as a technology / software company?*

**Answer: yes.** The review below uses the brand board (`previews/00-brand-board.png`), which is what a cold viewer sees first, and then the twenty applications.

### What a cold viewer sees on the brand board
| Signal | Where |
|---|---|
| "Building intelligent digital products." + "Software · SaaS · AI" | Hero tile, descriptor lockup, footer |
| Capability chips: SaaS platforms, AI software, Automation, APIs, Data, Web & mobile | Hero tile |
| A real B2B SaaS dashboard (orders, on-time delivery, automation rate, workflows) | SaaS UI tile |
| An AI assistant that answers with cited sources and asks for approval before acting | AI interface tile |
| An API console with keys, webhooks and a curl request | API & developers tile |
| Platform architecture: Zirven → shared services (identity, data, AI, API) → products | Brand architecture tile |
| A product portfolio: VEVO (live), Product 02, Product 03, Zirven Solutions | Architecture tile, app-icon tile |
| Technology icon family (SaaS, AI, API, cloud, data, database, workflow, security…) | Icons tile |
| Website, mobile app, business card and office signage in the same system | Bottom rows |

### Residual risks and how they are handled
1. **The symbol alone is abstract.** Seen in isolation, the Summit Z reads as "Z, upward, precise", not specifically "software". The system carries the technology meaning: descriptor lockup, product UI, icons, code. Rule: on first contact (website header, pitch deck, events, LinkedIn), use the logo with the descriptor or alongside product UI.
2. **Hype vocabulary appears in the guidelines,** deliberately, as "never use" examples in sections 01 and 22. The audit lists each one as an allowed reference.
3. **Placeholders.** Product 02 and 03, customer names, people, metrics and the zirven.com domains are illustrative. Replace them before publication (see README).
4. **Trademark.** The visual review found no look-alike Z marks, but a formal search (classes 9, 35, 42) is still required.

### Verdict
The identity reads as a **technology and software company that builds and owns SaaS and AI products**. No artefact in the package still says "discount / coupon company", "restaurant app", "travel service" or "e-commerce discount app". The redesign passes the semantic audit.
